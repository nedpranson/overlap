# Overlap

Overlap is an overlay designed to seamlessly see and control your music in-game.

## ✨ Features

- **Playback Panel:** View the track that is currently playing.
- **Fast and Lightweight:** Made with high-performance concerns.

## 🏁 Getting Started

### Prerequisites:
- Windows 10 or 11.

### Installation:
1. Navigate to [latest releases](https://github.com/nedpranson/overlap/releases).
2. Download the zip file `overlap-1.0.0-alpha.1.zip`.
3. Run the application by opening `overlap.exe`.
